유튜브 숏폼 · 장면 그림

장면 그림 켜기ChatGPT 구독으로 그림 그리기(Codex · 윈도우 PC 워커)

윈도우 PC의 워커 컨테이너(nomute-worker)가 켜져 있고 Codex에 ChatGPT로 로그인돼 있으면, 유튜브 숏폼의 장면 그림과 카드·요약 썸네일을 네 ChatGPT 구독으로 그려. API 요금은 따로 안 나가. 꺼져 있으면 GPT 이미지·입체는 모션 그래픽으로, 그록은 첫 그림 없이 바로 영상으로, 카드·썸네일은 Gemini(종량제)로 자동으로 넘어가. 한 번만 해두면 돼.

0어디서 그리나

그림을 그리는 곳은 항상 켜 둔 윈도우 PC 한 대야(운영자 확정 · 261014). 표시등에 PC 켜짐이 보이면 그릴 수 있는 상태야.

상태 보기 = PC에서 상태확인.cmd → 「워커」(모드 live = 그린다 · standby = 일부러 쉼 · r2-auth·r2-error = 저장소 문제). 설치·로그인 다시·계정 추가 = 아래 한 줄(파란 창에 나온 주소·코드를 브라우저에서 넣기):

"%USERPROFILE%\nomute-runner\src\scripts\win\설치.cmd" -Only worker

위 한 줄은 Win+R(실행 창)에 붙여 넣는다. PowerShell 창에서 치려면 맨 앞에 & 를 붙인다(따옴표 경로 뒤에 인자가 오면 파서 오류).

1ChatGPT로 로그인

설치기(0단계)가 로그인까지 물어보지만, 따로 다시 할 수도 있어. PC의 워커 폴더에서:

cd %USERPROFILE%\nomute-runner\src\scripts\win\worker
docker compose run --rm -T worker login 1

창에 나온 주소와 코드를 아무 기기 브라우저에서 열어 ChatGPT 계정으로 넣어(15분 유효). 확인:

docker compose run --rm -T worker status

accounts=1 이상이면 성공이야.

⚠ 주소가 https://auth.openai.com/codex/device 인지 확인하고, 그 창에 방금 뜬 코드만 넣어. 메일·메시지·다른 사이트·남이 알려 준 코드는 절대 넣지 마(내 ChatGPT를 남의 기기에 넘기는 사기 수법).

「장치 코드 로그인」이 막혀 있으면 ChatGPT 웹 → 설정 → 보안 → 장치 코드 로그인 허용을 켜고 다시 해.

2두 번째 계정 (선택)

구독 계정이 2개면 두 번째 계정을 따로 로그인해 둬. 첫 계정 한도가 차면 자동으로 넘어가.

docker compose run --rm -T worker login 2

같은 브라우저면 첫 계정으로 바로 승인될 수 있어 — 시크릿 창에서 열어.

3그림 1장 시험

큐·러너와 무관하게, 로그인된 계정이 실제로 그리는지만 본다:

docker compose run --rm -T worker selftest
docker compose run --rm -T worker selftest-img

✅ 성공이면 컨테이너 안에 그림이 생겨(장면 그림 = ~/nomute-ys/selftest/test.png · 카드·썸네일 = ~/nomute-img/selftest/test.png). ❌가 나오면 마지막 한 줄이 사유야 — 그 줄을 그대로 알려줘.

4표시등 확인

에디터 → 영상 스튜디오 → 유튜브 탭의 "장면 그림" 옆 표시등:

표시뜻
PC 켜짐그림을 그릴 수 있어. 1분마다 갱신돼.
PC 작업 중지금 그리는 중이야.
PC 꺼짐3분 넘게 신호가 없어. 이때 만들면 GPT 그림 대신 모션 그래픽으로 나와.
로그인 필요워커는 돌고 있는데 Codex가 ChatGPT로 로그인돼 있지 않아 → 1단계.

러너도 같은 표시등을 봐 — 꺼져 있으면 그림 잡을 아예 안 보내고 바로 대체 경로로 간다(헛대기 0).

5PC가 잠들지 않게

PC가 절전에 들어가면 "꺼짐"으로 보여. 설치기가 「전원 연결 중 절전 끄기」를 물어보니 거기서 예를 고르면 돼(나중에 바꾸려면 윈도우 설정 → 시스템 → 전원).

!꼭 알아둘 것

  • 로그인 정보는 워커 컨테이너 볼륨(worker-home)의 ~/.codex/auth.json에 저장돼. 비밀번호처럼 다뤄 — 채팅·메신저·깃에 절대 붙이지 마. docker compose down -v는 이 로그인을 지운다.
  • 그림은 글자 작업보다 구독 한도를 3~5배 빨리 써(OpenAI 공식 안내). 장면 7개 = 그림 7장.
  • 한 장면이 실패해도 영상은 나와. 그 장면만 모션 그래픽으로 채워져.
  • 장면 그림과 카드·썸네일은 한 회차에 한 장씩 번갈아 그려 — 구독 한도와 CPU를 둘이 동시에 쓰지 않게.
